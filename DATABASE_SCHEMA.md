# Database Schema and Sample Data

This project uses MongoDB with Mongoose models in `backend/models`.

## Entity Relationships
- `Procurement.recordedBy` -> `User._id`
- `Sale.recordedBy` -> `User._id`
- `CreditSale.recordedBy` -> `User._id`
- `CreditSale.trustedBuyer` -> `TrustedBuyer._id`
- `CreditSale.payments.receivedBy` -> `User._id`
- `TrustedBuyer.recordedBy` -> `User._id`

## Collections

### 1. users (`User`)
- `name` (String, required, min 2, alphanumeric/space/period)
- `username` (String, required, unique)
- `password` (String, required, hashed)
- `profileImage` (String, default empty)
- `role` (Enum: `director`, `manager`, `sales_agent`)
- `branch` (Enum: `Maganjo`, `Matugga`; required for non-director)
- `canViewCrossBranchTotals` (Boolean, default `false`)
- `createdAt`, `updatedAt` (timestamps)

Indexes:
- `{ branch: 1, role: 1 }`

### 2. procurements (`Procurement`)
- `produceName` (String, required, normalized)
- `produceType` (Enum: `Beans`, `Grain Maize`, `Cow peas`, `G-nuts`, `Soybeans`)
- `sourceType` (Enum: `individual`, `company`, `kgl_farm`)
- `dateReceived` (Date, required)
- `timeReceived` (String, required)
- `tonnageKg` (Number, required, min 100; min 1000 for `individual` source)
- `costUgx` (Number, required, min 10000)
- `dealerName` (String, required)
- `dealerContact` (String, required, Uganda format)
- `branch` (Enum: `Maganjo`, `Matugga`)
- `sellingPrice` (Number, required, min 10000)
- `recordedBy` (ObjectId ref `User`, required)
- `createdAt`, `updatedAt` (timestamps)

Indexes:
- `{ branch: 1, createdAt: -1 }`
- `{ branch: 1, dateReceived: -1 }`
- `{ branch: 1, produceType: 1, sourceType: 1 }`

### 3. sales (`Sale`)
- `produceName` (String, required, normalized)
- `produceType` (Enum: `Beans`, `Grain Maize`, `Cow peas`, `G-nuts`, `Soybeans`)
- `tonnageKg` (Number, required, min 1)
- `amountPaidUgx` (Number, required, min 10000)
- `buyerName` (String, required)
- `salesAgentName` (String, required)
- `date` (Date, required)
- `time` (String, required)
- `branch` (Enum: `Maganjo`, `Matugga`)
- `recordedBy` (ObjectId ref `User`, required)
- `createdAt`, `updatedAt` (timestamps)

Indexes:
- `{ branch: 1, createdAt: -1 }`
- `{ branch: 1, date: -1 }`
- `{ branch: 1, produceName: 1, produceType: 1 }`

### 4. creditsales (`CreditSale`)
- `buyerName` (String, required)
- `nationalId` (String, required, 14-char uppercase alphanumeric)
- `location` (String, required)
- `contact` (String, required, Uganda format)
- `amountDueUgx` (Number, required, min 10000)
- `amountPaidUgx` (Number, default 0)
- `balanceUgx` (Number, defaults to `amountDueUgx`)
- `salesAgentName` (String, required)
- `dueDate` (Date, required)
- `produceName` (String, required, normalized)
- `produceType` (Enum: `Beans`, `Grain Maize`, `Cow peas`, `G-nuts`, `Soybeans`)
- `tonnageKg` (Number, required, min 1)
- `dateOfDispatch` (Date, required)
- `branch` (Enum: `Maganjo`, `Matugga`)
- `recordedBy` (ObjectId ref `User`, required)
- `trustedBuyer` (ObjectId ref `TrustedBuyer`, required)
- `isPaid` (Boolean, default `false`)
- `payments[]`:
  - `amountUgx` (Number, required, min 1)
  - `paidAt` (Date, default now)
  - `receivedBy` (ObjectId ref `User`, required)
- `createdAt`, `updatedAt` (timestamps)

Indexes:
- `{ branch: 1, createdAt: -1 }`
- `{ branch: 1, dateOfDispatch: -1 }`
- `{ branch: 1, dueDate: 1, isPaid: 1 }`
- `{ trustedBuyer: 1, createdAt: -1 }`

### 5. trustedbuyers (`TrustedBuyer`)
- `name` (String, required)
- `nationalId` (String, required)
- `location` (String, required)
- `contact` (String, required, Uganda format)
- `branch` (Enum: `Maganjo`, `Matugga`)
- `recordedBy` (ObjectId ref `User`, required)
- `createdAt`, `updatedAt` (timestamps)

Indexes:
- Unique `{ nationalId: 1, branch: 1 }`
- `{ branch: 1, createdAt: -1 }`

### 6. pricesettings (`PriceSetting`)
- `branch` (Enum: `Maganjo`, `Matugga`)
- `produceType` (Enum: `Beans`, `Grain Maize`, `Cow peas`, `G-nuts`, `Soybeans`)
- `priceUgx` (Number, required, min 10000)
- `createdAt`, `updatedAt` (timestamps)

Indexes:
- Unique `{ branch: 1, produceType: 1 }`

### 7. stocknotifications (`StockNotification`)
- `branch` (Enum: `Maganjo`, `Matugga`)
- `produceName` (String, required, normalized)
- `produceType` (Enum: `Beans`, `Grain Maize`, `Cow peas`, `G-nuts`, `Soybeans`)
- `category` (Enum: `out_of_stock`, default `out_of_stock`)
- `message` (String, required)
- `isRead` (Boolean, default `false`)
- `readAt` (Date, nullable)
- `createdAt`, `updatedAt` (timestamps)

Indexes:
- `{ branch: 1, category: 1, produceName: 1, produceType: 1, isRead: 1 }`

### 8. stocklocks (`StockLock`)
- `key` (String, required, unique)
- `ownerId` (String, required)
- `expiresAt` (Date, required)
- `createdAt`, `updatedAt` (timestamps)

Indexes:
- TTL index `{ expiresAt: 1 }` with `expireAfterSeconds: 0`

## Sample Data
Sample data is generated by `backend/seedData.js`.

Important: running the seeder clears existing data in the following collections first:
- users
- procurements
- sales
- creditsales
- trustedbuyers

Seed command:
```bash
cd backend
node seedData.js
```

Seeded users (password `password123`):
- Director: `orban`
- Managers: `managerA`, `managerB`
- Sales agents: `agent1A`, `agent2A`, `agent1B`, `agent2B`

Sample records seeded:
- Procurement records across both branches
- Cash sales records across both branches
- Trusted buyers for both branches
- Credit sales linked to trusted buyers
