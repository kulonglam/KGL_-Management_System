## Goal
Validate usability and efficiency for the three primary roles:
- Director
- Manager
- Sales Agent

Target acceptance:
- Task success rate >= 90%
- Critical task completion in <= 3 clicks from dashboard for common actions
- No blocker-level accessibility issues

## Test Scenarios

### 1. Manager Workflow
1. From dashboard, record procurement.
2. Record a cash sale.
3. Record a credit sale.
4. Open inventory and identify low/out-of-stock items.
5. Open records and verify newly created entries.

Capture:
- Success/failure
- Completion time
- Misclick count
- User confusion notes

### 2. Sales Agent Workflow
1. From dashboard, record cash sale.
2. Record credit sale.
3. Verify stock before submitting sale.
4. Check own records pages.

Capture:
- Success/failure
- Completion time
- Validation clarity feedback

### 3. Director Workflow
1. Switch between branch scopes.
2. Change period filters.
3. Export CSV/Excel/PDF.

Capture:
- Success/failure
- Filter clarity
- Export reliability

## Accessibility Sweep
- [ ] Keyboard-only navigation works for core pages.
- [ ] Focus state is visible on interactive controls.
- [ ] Color contrast acceptable for text and controls.
- [ ] Forms announce errors and success states.
- [ ] Dialogs trap focus and close via Escape.
